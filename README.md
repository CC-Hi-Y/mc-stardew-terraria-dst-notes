# Minecraft / Stardew / Terraria / DST — verified mechanics notes

A small dataset of game mechanics that are checkable in-game, collected while writing guides for [tolistn.online](https://www.tolistn.online/). No tier lists, no speculation — only things you can reproduce, plus a separate, clearly-labelled set of community legends that the developers never confirmed.

## What's in here

- **[data/facts.json](data/facts.json)** — 78 entries, each with `game`, `type` (`fact` | `legend` | `rule`) and `text`.
  - `fact` — reproducible in-game
  - `legend` — widely repeated, never confirmed by the developer
  - `rule` — old player habit that still holds
- The same 78 entries run in the "Field notes" panel on the site's homepage, shuffled per visit.

## Why the split matters

A lot of "did you know" lists mix mechanics with urban legends. Mixing them is how people end up farming a mob that does not exist. The `type` field is the whole point: if you cannot reproduce it, it is a legend, and it says so.
